\begin{abstract}
This teaching note connects residual arithmetic, intercept fitting, and the interpretation of empirical error using five synthetic observations. A fixed baseline \(2x\) has residual \(3\) at every observation, so adding \(3\) reproduces the targets. An observation table, squared-error decomposition, executable calculation, and two figures provide complementary checks. Answer-keyed prompts distinguish optimality from exact fit, objective-specific minimizers from their coincident values, and reported errors from the target observations that determine them.
\end{abstract}

\section{Introduction}

The intended audience is learners familiar with averages and elementary algebra who are beginning residual-based error analysis. The sequence targets three possible confusions: assuming that minimization guarantees zero error, treating mean and median corrections as interchangeable, and interpreting an error value without tracing how its targets were used.

The contribution is a fully specified exercise with explicit criteria for a correct explanation. Each observation can be followed through baseline prediction, residual formation, correction, and evaluation. Rows, algebra, code, and target dependencies describe the same calculation; the diagnostic prompts require connections between them. The equation \(y_i=2x_i+3\) defines the five supplied target values.

\section{Related Work}

Intercept fitting asks which constant to add while keeping slope \(2\) fixed. Residual analysis identifies the remaining error and the condition for exact fit. Evaluation tracing identifies the observations used to determine the correction and its reported errors.

The instructional sequence coordinates these questions through checkable evidence: rows establish the residuals, the decomposition establishes squared-error optimality, the pairing argument identifies an absolute-error minimizer, and the diagram locates the uses of the targets. The three recorded offsets provide arithmetic checks within this sequence.

\section{Method}

\subsection{Finite Setting and Residual-Mean Correction}

Table~\ref{tab:observations} contains the complete supplied observations. With fixed baseline \(\widehat y_i^{(0)}=2x_i\), define residuals and candidate corrected predictions by
\[
r_i=y_i-\widehat y_i^{(0)},\qquad
\widehat y_i(b)=2x_i+b.
\]
The selected correction is
\[
b_\star=\frac{1}{5}\sum_{i=1}^{5}r_i=3,\qquad
\widehat y_i^{\,\mathrm{corr}}=\widehat y_i(b_\star).
\]
Every residual is \(3\), so this correction reproduces every target.
Figure~\ref{fig:residual_workflow} traces the calculation, labeling the selected correction \(b=3\).

\subsection{Squared and Absolute Error}

For a finite residual vector \(r_1,\ldots,r_n\), let
\(\bar r=n^{-1}\sum_i r_i\). Expanding around its mean gives
\begin{align*}
\operatorname{MSE}(b)
&=\frac{1}{n}\sum_{i=1}^{n}(r_i-b)^2\\
&=\frac{1}{n}\sum_{i=1}^{n}(r_i-\bar r)^2
  +(b-\bar r)^2,\\
\operatorname{MSE}(0)-\operatorname{MSE}(\bar r)
&=\bar r^{\,2}.
\end{align*}
The cross term vanishes because \(\sum_i(r_i-\bar r)=0\).
The nonnegative final term establishes that \(b=\bar r\) minimizes
squared error. The minimum equals the centered squared residual
average, which is zero precisely when every residual equals \(\bar r\).
Any residual variability makes this minimum positive. Optimality
and exact fit therefore require separate justifications.

For absolute error, order five residuals as
\(r_{(1)}\leq\cdots\leq r_{(5)}\).
The distances to \(r_{(1)}\) and \(r_{(5)}\) have minimum sum
throughout their intervening interval; the same holds for
\(r_{(2)}\) and \(r_{(4)}\).
The median \(m=r_{(3)}\) lies in both intervals and makes its own
distance zero. Hence it minimizes
\(\operatorname{MAE}(b)=5^{-1}\sum_i|r_i-b|\).
The squared-error decomposition also gives
\[
\operatorname{MSE}(m)-\operatorname{MSE}(\bar r)
=(m-\bar r)^2.
\]
Thus unequal mean and median values select different optimal
constants for the two objectives. For the supplied constant
residual vector, both equal \(3\).

\section{Experiments}

\subsection{Calculation Setup and Reproducibility}

One deterministic base R calculation evaluates offsets \(b=0,1.5,3\)
on the five observations. The following code reproduces the selected
correction and recorded error table.

\begingroup
\small
\begin{verbatim}
x <- c(-2, -1, 0, 1, 2)
y <- c(-1, 1, 3, 5, 7)
r <- y - 2*x
b <- mean(r)
offsets <- c(0, 1.5, b)
print(data.frame(
  b = offsets,
  MAE = sapply(offsets, function(a) mean(abs(r - a))),
  MSE = sapply(offsets, function(a) mean((r - a)^2))))
\end{verbatim}
\endgroup

\subsection{Recorded Errors and Interpretation}

For these observations,
\[
\operatorname{MAE}(b)=|3-b|,
\qquad
\operatorname{MSE}(b)=(3-b)^2.
\]
Table~\ref{tab:errors} records the values. The intermediate offset
halves every residual and quarters MSE.
Figure~\ref{fig:intercept_error} plots precisely these three checks
of the arithmetic; the decomposition establishes optimality.

A prediction and its corresponding target are distinct inputs to
an error calculation. In Figure~\ref{fig:residual_workflow}, the
targets enter both residual averaging and final comparison.
Accordingly, the recorded scores quantify agreement on the
correction observations. Constant residuals explain the zero:
their centered squared residual average vanishes. Tracing target
use explains which observations support that score.

\paragraph{Diagnostic prompts and answer criteria.}
The exercise asks learners to explain:
(i) why \(b=3\) is optimal and why its error is zero;
(ii) which residual summaries minimize the two objectives and why
they agree here; and
(iii) which observations supply each target-dependent step in
Figure~\ref{fig:residual_workflow}.
A complete answer must identify the nonnegative
\((b-\bar r)^2\) term and the vanishing centered residuals;
identify the mean and median using the respective arguments;
and trace both target paths to the same five rows.
These criteria assess the explanations accompanying the numerical
answers.

\section{Conclusion}

The note supplies a checkable calculation and explicit explanation
criteria. The resulting exercise connects row-level residuals,
objective-specific minimizers, the condition for exact fit, and
the target dependencies underlying the recorded errors.
