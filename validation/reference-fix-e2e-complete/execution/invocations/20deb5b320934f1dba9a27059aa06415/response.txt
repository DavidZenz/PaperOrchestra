Detailed Description: **Canvas and style**
- Pure white background (#FFFFFF), no border or frame around the canvas.
- Target width is one single column (about 3.4 in). Scale the TikZ picture to fit; the node set is designed for roughly 16 cm × 8 cm before scaling.
- Text is Computer Modern via LaTeX math mode, \small for body labels and \footnotesize for sub-labels. Math symbols are italic.
- Node boxes are rounded rectangles with corner radius 2 mm, border width 0.6 pt, and a soft fill. Arrows are 0.8 pt dark gray (#333333) with filled triangular heads, except where noted.
- No title, no caption, no legend, no axes, no extra modules or experiments.

**Layout (cm, node centers, origin bottom-left)**
- Top row at y = 5.5: four nodes left to right at x = 1.8, 6.0, 10.2, 14.2. Each node is 2.8 × 1.6 cm. Gaps between nodes are about 1.4 cm.
- Bottom row at y = 2.6: "Corrected prediction" at x = 10.2 (3.2 × 1.6 cm), and "Evaluation" at x = 14.2 (2.8 × 1.6 cm).
- Reuse route runs along the bottom of the canvas, at y ≈ 0.8 cm.

**Nodes, from left to right and top to bottom**

1. **Inputs and targets** (top-left, x = 1.8).
   - Fill #EAF1F8, border #4A6B8A.
   - Text lines: "Observed inputs and targets", then $x_i \in \{-2,-1,0,1,2\}$, then $y_i = 2x_i + 3$, then the values $\{-1,1,3,5,7\}$ in a smaller font.
   - Index $i = 1,\dots,5$ appears as a subscript only.

2. **Fixed baseline** (top, x = 6.0).

   - Fill #E3EEF9, border #2F5F8A.
   - Text: "Corrected prediction", then $\hat y_i = 2x_i + b$, then values $\{-1,1,3,5,7\}$ in a smaller font.

6. **Evaluation** (bottom-right, x = 14.2).
   - Fill #F2F2F2, border #7F7F7F, dashed border (on-dash 3 pt, off-dash 2 pt).
   - Text: "Evaluation on the same five points", then $e_i = y_i - \hat y_i = 0$, then "in-sample arithmetic check".

**Arrows and their labels**

- **Inputs → Baseline:** straight solid arrow from the right edge of node 1 to the left edge of node 2. Label above: $x_i$. Label below in a smaller font: "fixed map".
- **Inputs → Residuals (targets):** curved solid arrow that leaves the top of node 1, arcs above the baseline node, and enters the top of node 3. Label at its apex: $y_i$. This shows the observed targets feeding the residual directly.
- **Baseline → Residuals:** straight solid arrow from node 2 to node 3. Label: $-\,2x_i$.
- **Residuals → Scalar correction:** straight solid arrow from node 3 to node 4. Label above: "mean over the five points".
- **Baseline → Corrected prediction:** vertical solid arrow down from the bottom of node 2 to the left side of node 5, routed as an L-shape. Label: $2x_i$.
- **Scalar correction → Corrected prediction:** vertical arrow down from the bottom of node 4 to the right side of node 5, routed as an L-shape. This arrow is thick, 1.2 pt, in purple #6A4C93, and labeled $+\,b$. It is the explicit scalar dependency.
- **Corrected prediction → Evaluation:** straight solid arrow from node 5 to node 6. Label above: $\hat y_i$ compared with $y_i$.
- **Reuse route:** dashed dark-gray arrow (0.8 pt, dash pattern 4 pt on, 2 pt off). It leaves the bottom of node 1, runs down to y ≈ 0.8 cm, runs right to x = 14.2, and rises into the bottom of node 6. Centered label on the horizontal segment, in italics: "same five observations reused for correction and evaluation".

**Semantic requirements to preserve**
- Observed targets and baseline predictions visibly determine the residuals. The residual node is the only point where $y$ and $2x$ meet.
- The residuals visibly determine the single scalar $b$. The mean node has exactly one incoming arrow from the residual node and produces one scalar output.
- The scalar $b$ visibly feeds only the corrected prediction, not the baseline and not the targets.
- The reuse route makes clear that the same five observations are used in both the correction step and the evaluation step.
- Do not add error bars, confidence intervals, timing values, train/test splits, optimizers, architectures, or external datasets. Do not state or imply generalization or novelty.
