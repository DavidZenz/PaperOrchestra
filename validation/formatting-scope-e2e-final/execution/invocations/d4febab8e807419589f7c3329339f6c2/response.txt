**Title:** Recorded Mean Squared Error for Three Intercept Corrections

## Data and variable mapping

The plot shows exactly three recorded observations from the experimental log. No other points, curves, or intervals are drawn.

| Point | b (x-axis) | MSE (y-axis) | Label |
|---:|---:|---:|---|
| 1 | 0 | 9 | "(0, 9)" |
| 2 | 1.5 | 2.25 | "(1.5, 2.25)" |
| 3 | 3 | 0 | "(3, 0)" |

- **x channel:** `b`, the added intercept correction. Values are 0, 1.5, and 3.
- **y channel:** `MSE`, the mean squared error. Values are 9, 2.25, and 0.
- **hue / shape / size:** A single series. All points share one fill and one marker shape, so no legend is needed.

**Supporting arithmetic (not plotted):** The five observations are (x, y) = (-2, -1), (-1, 1), (0, 3), (1, 5), (2, 7). The residuals y − 2x are all 3, so the correction is b = mean(y − 2x) = 3. For each candidate b, the errors y − (2x + b) are 3, 1.5, and 0 respectively, which give the MAE and MSE values in the table above. The MAE values (3, 1.5, 0) are not plotted.
