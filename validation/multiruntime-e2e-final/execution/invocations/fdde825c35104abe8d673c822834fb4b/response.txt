**Variable mapping:**
- **x channel:** added intercept correction `b`, the value added to `2x` (the baseline predictor). Ticks at 0, 1.5, 3.
- **y channel:** mean squared error, `mean((y - (2x + b))^2)` over the five observations. Ticks at 0, 3, 6, 9.
- **hue / shape:** none. All points share one color and one shape, since there is only one series.

**Provenance (for the caption and notes, not plotted):** the five synthetic observations are (x, y) = (−2, −1), (−1, 1), (0, 3), (1, 5), (2, 7). Their residuals against `2x` are all 3, so the correction is `b = mean(y − 2x) = 3`. The MAE column (3, 1.5, 0) is in the source table but is not plotted.

## Reproducible R/ggplot2 source (described, not written to disk)

```r
library(ggplot2)

# Recorded results only; no interpolation or extra measurements
df <- data.frame(
  b   = c(0, 1.5, 3),
  mse = c(9, 2.25, 0)
)

p <- ggplot(df, aes(x = b, y = mse)) +
  geom_point(shape = 16, size = 4, colour = "#1F4E79") +
  geom_text(aes(label = sprintf("%.2f", mse)),
            vjust = -1.2, size = 3.5, colour = "#333333") +
  scale_x_continuous(breaks = c(0, 1.5, 3), limits = c(-0.3, 3.3)) +
  scale_y_continuous(breaks = c(0, 3, 6, 9), limits = c(-0.6, 10.5)) +
  labs(
    title   = "Recorded Mean Squared Error at Three Intercept Corrections",
    x       = "Added intercept correction b",
    y       = "Mean squared error (MSE)",
    caption = paste(
      "Each point is a recorded result. The same five synthetic observations,",
      "(x, y) = (−2, −1), (−1, 1), (0, 3), (1, 5), (2, 7), determine the correction",
      "b = mean(y − 2x) = 3 and also evaluate it. The plot shows finite arithmetic",
      "on these observations, not predictive generalization. No held-out data,",
      "fitted curve, or uncertainty interval is shown."
    )
  ) +
  theme_classic(base_size = 12) +
  theme(
    plot.title         = element_text(size = 13, face = "bold", colour = "#111111", hjust = 0),
    plot.caption       = element_text(size = 8.5, face = "italic", colour = "#555555", hjust = 0),
    axis.title         = element_text(size = 12, face = "bold", colour = "#222222"),
    axis.text          = element_text(size = 10, colour = "#444444"),
    axis.line          = element_line(linewidth = 0.5, colour = "#444444"),
    panel.grid.major.y = element_line(linewidth = 0.3, colour = "#E5E5E5"),
    panel.grid.major.x = element_blank(),
    panel.grid.minor   = element_blank(),
    legend.position    = "none"
  )

# Vector PDF (editable, reproducible) and manuscript-compatible preview
ggsave("fig_intercept_error.pdf", p, device = cairo_pdf, width = 6, height = 4)
ggsave("fig_intercept_error_preview.png", p, width = 6, height = 4, dpi = 300)
```
