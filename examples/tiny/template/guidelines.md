# Workflow demonstration format

Produce an anonymous short technical note of approximately 700–1000 words using
the supplied article template. The note is a demonstration with synthetic finite
data. Its scientific claims must stay within that scope. Do not call the
calculation a novel algorithm or a benchmark result. Use the existing section
headings. No appendix is required. Include the supplied figure and the measured
error table, with readable captions. Figures and tables must fit inside margins.
The template uses a single column, 11-point type and one-inch margins. Keep the
title anonymous. Citations must use only keys verified by the literature stage.
